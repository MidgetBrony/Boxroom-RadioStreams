# BOXROOM Radio Streams 1.2.2

This corrective release makes the public package version consistent across the
source, assembly metadata, Git tag, release asset, and BoxMate manifest.

## Changes

- Identifies the Melon and managed assembly as version 1.2.2.
- Publishes the versioned asset `Boxroom-RadioStreams.1.2.2.zip`.
- Adds `SHA256SUMS.txt` verification to the BoxMate manifest.

The earlier 1.2.1 GitHub release contained a 1.2.0 assembly in an asset named
`Boxroom-RadioStreams.1.2.0.zip`. That release remains unchanged for history;
1.2.2 is the first fully reconciled package.
